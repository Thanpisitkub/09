# Stage 4: เวอร์ชันอนิเมะ (แมปใหม่ทั้งหมด + จับตัวละครปริศนา)

**ยังไม่ได้ทดสอบใน Roblox Studio** — เปิดครั้งแรกอาจมี error ให้ส่งข้อความจาก `/console` มาให้แก้

## ตัวละครและโลก
- สัตว์ 72 ตัวถูกแทนด้วย **ตัวละครสไตล์อนิเมะ 72 ตัว** ที่ผมออกแบบเอง (เป็น "ประเภทตัวละคร" เช่น Petal Girl, Rookie Ninja, Star Witch, Titan Commander ไม่ใช่ตัวละครของอนิเมะเรื่องใดจริง เพราะติดลิขสิทธิ์) แบ่งเป็น 12 โซน: Sakura Village, Ninja Dojo Hills, Samurai Castle, Magic Academy, Spirit Shrine, Pirate Seas, Neon Tokyo, Mecha Wasteland, Demon Hunt Forest, Isekai Kingdom, Hero Academy City, Celestial Heaven
- แมปสร้างใหม่หมดจากโค้ด: ซากุระ ประตูโทริอิ โคมหิน บ้านญี่ปุ่น หอคอยเวทมนตร์ ศาลเจ้า เรือโจรสลัด ตึกนีออน หุ่นเมคา ป่ามาร ปราสาทอิเซไก ตึกฮีโร่ ประตูสวรรค์ แต่ละโซนมีสีพื้น หมอก และแสงของตัวเอง แสงเป็นโทนอนิเมะยามเย็น
- ฐานผู้เล่น: รั้วแดง ร้านอาหารผ้าใบแดง-ขาว วงกลมเรืองแสงสีชมพู คอกกลายเป็น "TEAM DOJO" ตัวละครที่วางไว้จะเดินเล่นเป็นป้ายรูปหน้า (portrait) ขอบสีตามความหายาก

## เกมเพลย์
- แตะ THROW: ตัวละครสะบัดแขนด้วยแอนิเมชัน **tool slash ของ Roblox** (ID สาธารณะ 522635514 ใช้ได้ทุกเกม และผู้เล่นอื่นเห็นด้วย) กล้องกระตุก FOV มีเส้นความเร็วแบบอนิเมะ อาหารหมุนลอยไปตกตามระยะของ Throw Power
- ตกแล้วเกิด **วงเวทมนตร์หมุน** และ **เงาปริศนา "?"** ลอยขึ้นจากวง แล้ววิ่งพุ่งมาที่ฐานของคุณ **ยังไม่รู้ว่าเป็นตัวอะไร** จนถึงฐานจึงแฟลชและเปิดการ์ดตัวละคร (รัศมีหมุนตามความหายาก, ป้าย NEW!)
- ขายตัวละครได้ที่ My Team → Sell

## UI
- สีใหม่โทนอนิเมะ (ชมพูซากุระ/ม่วงน้ำเงินเข้ม) ไอคอน FOLK ใช้ครบ: เพิ่มอีก 20 ไอคอนหน้า (FaceBeam, FaceAngry, ...) เป็นรูป portrait ของตัวละคร รวมไอคอนที่ต้องอัปโหลดทั้งหมด 58 ชิ้น (ระบบอัปโหลดเองตอน push ตามที่เขียนไว้ใน Stage 3)

## ข้อจำกัดที่ต้องรู้
- ไม่มีภาพตัวละครจริง ใช้ใบหน้าอีโมจิจากชุดไอคอน + สีผม ถ้าอยากได้รูปจริง ต้องมีภาพที่คุณมีสิทธิ์ใช้ แล้วผมจะต่อให้
- แอนิเมชันโยนเป็นของ Roblox ที่มีอยู่แล้ว ถ้าอยากได้ท่าเฉพาะของเกม ต้องสร้างและเผยแพร่แอนิเมชันภายใต้บัญชีเจ้าของเกม (ผมอัปโหลดแทนไม่ได้) จากนั้นเปลี่ยนค่า `SWING` ใน `src/client/Throw.luau`
- ถ้า ID แอนิเมชันโหลดไม่ได้ ระบบจะข้ามไปเฉยๆ ที่เหลือยังทำงาน
- ยังไม่มีเสียง/เพลง

# Stage 3: ไอคอน FOLK + UI ใหม่ + แมปแบบเกมจริง

**ยังไม่ได้ทดสอบใน Roblox Studio** — เปิดครั้งแรกอาจมี error ให้ส่งข้อความจาก `/console` มาให้แก้

## ไอคอน (ชุด FOLK ที่คุณส่งมา)
- เลือกมา 38 ไอคอนใส่ใน `assets/icons/` (เหรียญ ดาว โคลเวอร์ กล้ามแขน รถเข็น รอยเท้า กระเป๋า ฯลฯ + ผลไม้/อาหารบางชนิด) ส่วนไอคอนสัตว์ที่ไม่มีในชุดยังใช้อีโมจิ
- **ต้องอัปโหลดขึ้น Roblox ก่อนจึงจะเห็นรูป** ระบบทำให้เองตอน push: `tools/upload_icons.py` อัปโหลดเป็น Image ผ่าน Open Cloud แล้วสร้าง `src/shared/IconIds.luau` ให้ ไอคอนใดยังไม่มี id จะแสดงเป็นอีโมจิแทน เกมจึงไม่พัง
- **ต้องเพิ่มสิทธิ์ให้ API Key:** Creator Dashboard → Open Cloud → API Keys → คีย์ของคุณ → เพิ่ม API System **Assets** แบบ **Read และ Write** (เก็บ `universe-places` ไว้ด้วย) แล้วใส่ตัวแปร `ROBLOX_USER_ID` (เลข UserId ของคุณ) ใน GitHub → Settings → Secrets and variables → Actions → Variables (ถ้ารัน `setup.sh` ใหม่ มันจะถามให้)
- รูปที่เพิ่งอัปโหลดจะอยู่สถานะ "ตรวจสอบ" (Reviewing) ซักพัก ช่วงนั้นไอคอนอาจโล่ง ไม่ใช่บั๊ก
- **ลิขสิทธิ์:** README ในชุดไอคอนระบุว่าโฟลเดอร์ส่วนใหญ่ **ไม่มีไฟล์ลิขสิทธิ์/ไลเซนส์ให้** (มีแค่ Ranks และ Keyboard ที่เป็น CC0) ให้ตรวจสิทธิ์การใช้งานกับผู้ขายก่อนปล่อยเกมให้คนอื่นเล่น

## UI ใหม่ (มือถือ + คอม)
- เมนูซ้าย: Index / Map / Train / Settings, ขวา: โซนปัจจุบัน รายได้ ปุ่มเก็บเงิน, กลางล่าง: Shop / Animals / THROW / อาหาร

# Throw Food For Animals — Stage 2: runway map + plots + mobile deploy

**ยังไม่ได้ทดสอบใน Roblox Studio** (ไม่มี Studio ในสภาพแวดล้อมที่เขียน) ตรวจได้แค่โครงสร้างโค้ด รันครั้งแรกอาจมี error ให้แก้ทีละจุด

## แมปแบบเกมต้นฉบับ (สนามวิ่งยาว)
- ทุกคนยืนที่ **ฐานของตัวเอง** (10 ช่อง เรียงข้างกันที่ต้นสนาม) แล้วขว้างอาหารไปตามสนามยาวไปทาง -Z
- สนามแบ่งเป็น **12 โซน** ต่อกันเป็นเส้นตรง: ขว้างไกลแค่ไหน = ตกโซนไหน (ไม่มีเมนูเลือกพื้นที่แล้ว) ระยะเริ่มโซนอยู่ใน `Config.World.ZoneStarts`
- ขว้างไกลขึ้น = โชคเพิ่มสูงสุด +50% ที่ปลายสนาม; อาหารและ Luck ยังกำหนดชนิดสัตว์เหมือนเดิม
- แต่ละโซนมีพื้น ฉากประดับ แสง/หมอกของตัวเอง ป้ายชื่อโซน เสาประตู และป้ายระยะทุก 100 studs
- ในฐาน: จุดขว้างเรืองแสง, บาร์ดึงขึ้น (กดแล้วเปิดเทรน), ร้านอาหาร, ป้ายสัตว์, ป้ายแผนที่, ป้ายชื่อเจ้าของ, คอกสัตว์ที่สัตว์ซึ่งวางไว้เดินเล่นจริง
- ทั้งโลกสร้างจากโค้ด (`WorldBuilder.luau`) ไม่ต้องใช้ Studio วางของ

## ส่งขึ้น Roblox จากมือถือ (ไม่ใช้ Studio)
GitHub Actions จะรัน Rojo สร้างไฟล์เกมแล้วอัปโหลดผ่าน Open Cloud ให้เอง (ไฟล์ `.github/workflows/publish.yml`)

**ตั้งค่าครั้งเดียว**
1. สร้างเกมเปล่า (Experience) ที่ create.roblox.com → Creations ตั้งเป็น Private ไว้ก่อน แล้วจด **Universe ID** และ **Place ID** (ในหน้า Creations → เปิดเกม → Places)
2. Creator Dashboard → Open Cloud → API Keys → สร้างคีย์: เพิ่ม **universe-places** ใน Access Permissions, ใส่การดำเนินการ **Write**, เลือกเกมนี้ แล้วคัดลอกคีย์ (จะเห็นแค่ครั้งเดียว)
3. สร้าง GitHub repo (ตั้งเป็น Private) แล้วใน Settings → Secrets and variables → Actions:
   - Secret: `ROBLOX_API_KEY` = คีย์
   - Variables: `ROBLOX_UNIVERSE_ID`, `ROBLOX_PLACE_ID`
4. ใน Termux: `pkg install git gh unzip` → `unzip ThrowFoodForAnimals.zip && cd TFFA` → `bash setup.sh`
   สคริปต์จะถาม Universe ID, Place ID, API Key แล้วสร้าง repo ส่วนตัว ตั้ง secret/variable และ push ให้เอง (ข้อ 3 ข้างบนไม่ต้องทำมือ)

**ใช้งานประจำ:** แก้ไฟล์แล้ว push เข้า `main` ระบบจะ build + publish เอง (หรือกด Run workflow ที่แท็บ Actions แล้วเลือก Published/Saved) ผลสำเร็จจะเห็นเลขเวอร์ชัน แล้วเปิดเกมในแอป Roblox ที่ล็อกอินบัญชีเจ้าของเพื่อทดสอบ

**ดู error บนมือถือ:** ในเกม พิมพ์ `/console` ในแชท (เฉพาะเจ้าของเกม) เปิด Developer Console แท็บ Server/Client เพื่อดู log

**ข้อควรรู้**
- Place Publishing API จำกัด 10 ครั้ง/นาที และไม่อัปเดตอินสแตนซ์บางชนิด (EditableImage, EditableMesh, PartOperation, SurfaceAppearance, BaseWrap) — โปรเจกต์นี้ยังไม่ใช้
- ทุกครั้งที่ publish จะทับทั้ง place ไฟล์ที่ตั้งค่าใน Studio จะหาย ให้แก้ผ่านโค้ด/`default.project.json`
- ถ้าอยากเปิดให้เล่นจริง ให้เปลี่ยนเกมจาก Private เป็น Public ที่หน้าตั้งค่าเกม
- ถ้า workflow ติดตั้ง Rojo ไม่ได้ ให้เปลี่ยน `ROJO_VERSION` เป็นเวอร์ชันที่มีใน github.com/rojo-rbx/rojo/releases

## ติดตั้งแบบเดิม (มี Studio)
`rojo serve` → Connect ใน Studio, เปิด Enable Studio Access to API Services, ใส่ UserId ของคุณที่ `Config.Admin.StudioCreatorUserId` เพื่อทดสอบเมนูแอดมิน
